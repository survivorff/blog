## 发布 SOP（每次 Thread）

### 发布前

- [ ] 选对时间：北京时间 20-22 点（国内活跃）或 UTC 14:00（欧美下午）
- [ ] 避开重大行业事件（会被淹没）
- [ ] 检查每条推文是否 280 字符以内
- [ ] 准备好关键数据的截图/图表（可选，能增加传播）

### 发布中

- [ ] 复制第一条，点"Add another post"，粘贴第二条
- [ ] 重复直到整个 Thread 发完
- [ ] 发送前最后检查一遍拼写和链接

### 发布后 30 分钟

- [ ] 把 Thread 的链接发到自己的其他社交账号（Telegram、微信群）
- [ ] 如果有朋友在圈内，私信请求转发
- [ ] 关注评论，回复前 3 条
- [ ] 如果反响好，考虑 pin 到个人主页

### 发布后 24 小时

- [ ] 记录数据：转发、点赞、评论、点击
- [ ] 分析哪条推文留存率最高
- [ ] 如果是好 Thread（>50 转发），quote 发一条小总结扩散

## 持续运营

### 每周节奏

- 周二 / 周四：发 Thread（1 条/周）
- 周一 / 周三 / 周五：小推文（观察、评论、转发）
- 周末：轻量互动，不发新 Thread

### 月度复盘

- 哪篇 Thread 数据最好？为什么？
- 哪些话题引发了讨论？
- 哪些没人看？为什么？
- 调整下个月的发布策略

## 注意事项

1. **不要急**：Thread 效果通常要几小时到几天才显现
2. **不要自 quote 过多**：每 Thread 最多 quote 一次
3. **引发讨论比自说自话重要**：敢于写反常识观点
4. **用数据说话**：具体数字 > 空洞形容词
5. **真实经历比技术分析传播更广**：个人故事是社交资产
